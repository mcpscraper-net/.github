# MCPScraper

Scraping MCP servers, compared on a published rubric.

- **Website:** [mcpscraper.net](https://mcpscraper.net)
- **Blog:** [mcpscraper.net/blog](https://mcpscraper.net/blog) · **Guides:** [mcpscraper.net/guides](https://mcpscraper.net/guides)
- **Docs:** [mcpscraper.net/docs](https://mcpscraper.net/docs)
- **CLI:** [`mcpscraper`](https://github.com/mcpscraper-net/cli), live web pages as Markdown from your terminal ([docs](https://mcpscraper.net/docs/cli), [npm](https://www.npmjs.com/package/@mcpscraper-net/cli))

```bash
npx @mcpscraper-net/cli fetch https://example.com -o text
```
